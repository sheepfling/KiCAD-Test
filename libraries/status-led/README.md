# Status-LED training library

This controlled shared library supports the synthetic Arduino Uno and Raspberry Pi
status-LED examples. It is NOT FOR MANUFACTURE and does not establish a qualified
component, land pattern, mating connector, clearance, electrical rating or sourcing
decision.

Its controlled provenance and licensing records are [PROVENANCE.md](PROVENANCE.md)
and [LICENSE.md](LICENSE.md). Any adopted version must update those records and the
corresponding SHA-256 values in `catalog/libraries.json` under review.

The library record, owner and version also live in `catalog/libraries.json`. A
production library needs reviewed physical dimensions, a manufacturer-qualified part
mapping, datasheet evidence and a release/versioning policy before a board can
reference it.
